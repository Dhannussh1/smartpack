# Problem packets (demo stage)

Photos of the 5 packets we keep on the table for the live demo: ones whose **front-of-pack claim is misleading**.

For each packet add: `<product>-front.jpg`, `<product>-back.jpg`, and one line below on what the trick is.

| Product | Claim on front | What's actually inside |
|---|---|---|
| e.g. Brand X juice | "No added sugar" | Fruit juice concentrate + maltodextrin |
| | | |
| | | |
| | | |
| | | |

Good candidates: "No added sugar" juices, "Multigrain"/"Atta" biscuits with maida first, "Baked not fried" chips, "Sugar-free" sweets with maltitol, "Natural"/"Real fruit" drinks with colours, "High protein" snacks below the protein threshold.

Images in this folder are git-ignored (the repo is public). Only this README is committed.
