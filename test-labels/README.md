# Test labels

Drop label photos here (JPG/PNG/WebP). Used for building the scan pipeline, engine tests and the accuracy number on the pitch slide.

**Naming:** `<product>-back.jpg`, `<product>-front.jpg`, e.g. `parle-g-back.jpg`, `parle-g-front.jpg`

**Per product, take:**
- Back: ingredients list + nutrition table (flat, well lit, in focus)
- Front: brand name + claims ("No added sugar", "Multigrain"…)
- Dates: if mfg/expiry is printed separately (crimp, cap, bottom), a close-up of it

**Aim for ~20 products:** biscuits, chips, fruit juice, instant noodles, chocolate, health drink (Horlicks/Bournvita), breakfast cereal, "sugar-free"/"diet" items, protein bar, 2–3 local brands, 1–2 Tamil/Hindi-printed labels.

Images in this folder are git-ignored (the repo is public). Only this README is committed.
